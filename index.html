Privacy & storage
picochat has no backend: your messages and responses stay in this browser's memory and are cleared when the page is reloaded. Connection settings, API keys, recent values, and presets are saved only in this browser's local storage. When you send a message, the conversation and API key go directly to the endpoint you entered; that service's own privacy and retention rules still apply. Avoid using picochat on a shared or untrusted browser. You can also download this index.html file and open it locally if you prefer not to use a hosted copy.
